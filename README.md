# 🚀 DevHub

DevHub is a powerful, modern GitHub explorer and developer analytics web application built with React, Node.js, and MongoDB. It allows users to effortlessly search repositories and developer profiles, compare codebases and developer metrics, and save their favorite finds with a sleek dark-themed UI.

---

## 🌟 Features

- **GitHub Search Engine:** Instantly search live open-source repositories and creator profiles with built-in local caching and API quota tracking.
- **Repository & Developer Comparison:** Compare repositories side-by-side or analyze multiple developer metrics.
- **User Authentication:** Secure registration and login system with MongoDB backend and JWT sessions.
- **Personal Dashboard & Profile:** Manage saved favorite repositories and developers securely.
- **Modern UI/UX:** Designed with a clean charcoal theme (`#1c1c1c`), vibrant teal/cyan accents (`#009ca6`), responsive layouts, and smooth navigation.

---

## 🛠️ Tech Stack

### Frontend
- **React.js** (with React Router)
- **Tailwind CSS** (for styling)
- **Lucide React** (for icons)
- **Chart.js** (for visual analytics)

### Backend
- **Node.js** & **Express.js**
- **MongoDB** & **Mongoose** (Database & ODM)
- **JWT** (Authentication)
